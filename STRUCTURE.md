# Code map (read this instead of scanning the tree)
`app/src/main/java/com/ohadsam/specialevents/`
- `SpecialEventsApp`, `AppContainer` — application + manual DI (logger now; repos/prefs/scheduler as batches land).
- `MainActivity` — edge-to-edge, forced RTL, theme, `AppRoot`.
- `calendar/` — pure JVM (no Android): `HebrewCalendar`/`HebrewDate`, `HebrewNumerals`, `HebrewDay` (rollover), `SunCalc`, `HolyTimes` (candle lighting/havdalah), `Holidays` (Yom Tov days), `JewishCalendar` (festivals, fasts, Rosh Chodesh), `Parsha` (+`ParshaNames`, year-type pair table), `AnnualDates` (`OriginDate`, `DateRules`, `Occurrence`, `DualDate`), `Milestones`, `BarBatMitzvah`. `location/Places` — built-in places for zmanim.
- `domain/` — `EventModels` (`SpecialEvent`, `EventType`, `Tag`, ...), `EventTimeline` (pure: upcoming items, milestones, mitzvah). `data/` — `EventRepository`, `EventMapper`, `db/` (Room v1: events, tags, event_tags; schema JSON in `app/schemas`, committed by CI), `prefs/` (`AppSettings`, `SettingsRepository` over DataStore).
- `ui/upcoming/` (`UpcomingScreen`/`ViewModel`, `EventCard`), `ui/editor/` (`EditorScreen`/`ViewModel`, `HebrewDatePickerDialog`), `ui/detail/`, `ui/settings/` (`SettingsScreen`/`ViewModel`/`Components`), `ui/common/` (`ViewModelFactory`, `Labels`, `Formatters`). Pure helpers: `domain/EditorDate` (dual-calendar date being edited), `UpcomingFilter`/`TextSearch`, `IconSuggester`.
- `ui/calendar/` — `CalendarScreen` (level chips, prev/next, pinch zoom, layer menu), `CalendarViewModel` (prefs + events of the visible range), `MonthViews` (`MonthView`, `YearView`), `DayViews` (`DaySection`, `WeekView`, `DayView`, `AgendaView`), `CalendarLabels` (mark names/colours, titles). Pure: `domain/CalendarData` (month grids, visible ranges, stepping, zoom order), `EventTimeline.between`.
- `domain/search/` — pure search: `SearchStep` (chain steps), `SearchEngine` (window = intersection of range steps, then filters), `NaturalSearch` (Hebrew phrase -> steps), `SearchCodec`/`SavedSearch`/`SearchSuggestions`. `ui/search/` — `SearchScreen`/`ViewModel`; `data/prefs/SavedSearchRepository` (own DataStore file).
- `domain/reminders/` — pure: `ReminderModels` (`ReminderRule`, `SoundProfile`, enums), `ReminderPlanner` (offsets + Shabbat/Yom Tov shifting), `ReminderEngine` (what is due around now, from settings), `ReminderDefaults` + `ReminderLabels`. `reminders/` (Android): `ReminderScheduler` (one alarm = next reminder), `ReminderReceiver`/`BootReceiver`/`ReminderActionReceiver`, `NotificationHelper` (channels per profile, content), `ReminderState`. `permissions/PermissionHealth`; `ui/settings/ReminderHealthScreen`; `data/ReminderRepository`, `data/db/Migrations`.
- `ui/reminders/` — `EventRemindersScreen`/`ViewModel` (rules, suggestions, reset), `RuleEditorDialog` (offset, time, Shabbat policy, sound incl. system tone picker, scope). Pure: `ReminderSuggestions`, `ReminderEngine.nextFor` (preview).
- `contacts/` — `ContactImport` (+`ContactDateParser`, pure), `ContactsReader` (picker + address-book queries), `PhotoStore` (private downscaled JPEGs, LRU thumbs). `ui/contacts/` — `ImportContactsScreen`/`ViewModel`; `ui/common/EventAvatar`. DB v3 adds `contactPhone`/`contactEmail`.
- `domain/greetings/` — `GreetingRenderer` (placeholders + optional [[ ]] parts), `PhoneNumbers`, `GreetingCatalog` (built-in templates, ordering by type/gender/milestone). `greetings/GreetingSender` (WhatsApp wa.me / mail / SMS / share intents). `data/GreetingRepository` (custom templates + greeting history). `ui/greetings/` — `GreetingScreen`/`ViewModel`, `TemplatesScreen`/`ViewModel`. Reminder rules gained `timeMode` (FIXED/NIGHTFALL/MIDNIGHT) and greeting channels; DB v4 + v5.
- `greetings/` also: `GreetingContexts` (placeholder values), `AutoGreetingSender` (silent SMS for rules with autoSend, called by `ReminderScheduler`), `VoiceRecorder` (m4a in cache/voice, shared via FileProvider `${applicationId}.files`). `ui/greetings/VoiceSection`. `domain/greetings/SongSuggestions` (+ `AutoSend` policy). Rules gained `autoSend`/`templateId` (DB v6).
- `log/` — `AppLogger` (ring buffer + file), `LogBuffer`, `LogModel` (ported from Tehilim_Daily).
- `ui/theme/Theme.kt` — brand light/dark schemes (dynamic color optional). `ui/nav/` — `TopLevel` tabs, `Routes`, `AppRoot` (NavHost + bottom bar).
- `ui/common/PlaceholderScreen` — empty state for features landing later. `ui/settings/` — `SettingsScreen`, `LogsScreen`, `WhatsNewDialog`.
`app/src/main/assets/whatsnew.json` — current version's notes only. `app/sideload.jks` — committed on purpose (see build.gradle.kts).
Tests: `app/src/test` (log, calendar; `GoldenCalendarTest` compares with `src/test/resources/golden/*.csv`, regenerate via `tools/gen_golden.py` + `pip install pyluach==2.3.0`), `app/src/androidTest/SmokeTest`. CI: `.github/workflows/` (android-ci, latest-apk, release, ui-tests).
