# אירועים מיוחדים (Special Events)

אפליקציית אנדרואיד נייטיב (Kotlin + Jetpack Compose, עברית RTL) לניהול ימי הולדת, ימי נישואין, אזכרות ואירועים מיוחדים — עם לוח עברי ולועזי, תזכורות וברכות.

## יכולות עיקריות
- **אירועים**: הזנת תאריך חופשית (עברי/לועזי, שנה/גיל, יום בשבוע), סוגים, קבוצות (משפחה, חברים, עבודה…), תגיות, חיפוש מתקדם.
- **תצוגות**: אירועים קרובים, יום / שבוע / חודש / שנה, סינון, קיבוץ, מיון וקפיצה לאירוע או תאריך.
- **תזכורות וברכות**: כללי תזכורת לפי סוג וקבוצה, תבניות ברכה עם placeholders ועיצוב לפי יעד, שליחה בנגיעה אחת בוואטסאפ/מייל ו-SMS אוטומטי.
- **שיתוף והדפסה**: שיתוף אירועים נבחרים כקובץ, כרטיס אדם, הדפסת כרטיס ברכה / לוח חודשי / רשימה.
- **גיבוי**: ייצוא וייבוא (JSON מוצפן אופציונלי, CSV, ICS), גיבוי אוטומטי לתיקייה לבחירתך.
- **וידג'טים**, סנכרון ליומן המכשיר, נעילת אפליקציה, עזרה בהקשר ומדריך משתמש מובנה.

## החלטות מוצר
- וואטסאפ ומייל בשירות החינמי: אין שליחה שקטה — מוכנה הודעה לכל נמען ונוגעים "שלח". רק SMS נשלח אוטומטית.
- פרטיות: הנתונים נשארים במכשיר; ראו `docs/SECURITY.md`.

## פיתוח
- הנחיות: `CLAUDE.md`, תוכנית וסטטוס: `docs/PLAN.md`, מפרט: `docs/SPEC.md`, מבנה: `STRUCTURE.md`.
- אין Android SDK בסביבת הפיתוח בענן; **GitHub Actions הוא שער הבנייה והבדיקות היחיד** (`android-ci.yml`: ktlint, detekt, lint, בדיקות יחידה, הרכבה).
- מיזוג ל-`main` מפרסם את ה-APK בגרסת `latest`. כל עדכון מותקן כעדכון רגיל על הקיים (אותו חתום ואותו package) — ה-CI חוסם שינוי חתימה.
- skills לשימוש חוזר: `.claude/skills/android-native-dev`, `.claude/skills/release-checklist`.
